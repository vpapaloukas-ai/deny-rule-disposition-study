# Paths are relative to the experiment directory, and each ships at the same path in the bundle.
# One path per line. `#` starts a comment. A line beginning `#- ` names a file that exists and
# deliberately does NOT ship, with its reason; test_release_tooling.py fails if any file in
# harness/ is neither listed nor named that way, so no file can go unclassified.

#   check and analysis  analysers, oracles, prompt and manifest builders, and the measured/
#                       controls that produced and checked the reported numbers. Ship.
#   release             the pre-publication release scripts. Do NOT ship from harness/: the
#                       scrub rewrote their own rules in their published copies, and the
#                       assembler did not stop on a gate failure. Working versions are in
#                       release-tooling/.
